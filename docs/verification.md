## レビューと修正

別コンテキストのレビューで重要な問題を2件検出し、再現試験の失敗を確認した後に修正した。

1. ローカル別タブの同時書き込みで提出済み回答が消える問題。ブラウザのWeb Locksでルーム変更を直列化した。
2. 送信中に編集すると画面と提出ワードが食い違う問題。送信中は対象入力を固定し、成功・失敗後に編集可能へ戻した。

Critical・未対応Minorの指摘はない。レビューで実行できなかった本番接続は公開後の確認対象とし、実OS IMEの確認は残している。

## 実装時の判断

- 空の既存チェックアウトで実装ブランチを使い、別worktreeは作らなかった。既存の実装ファイルはなかった。
- BudouXをテキストノードと`wbr`に集約した。コピーされる原文を変えず、長い語はCSSで緊急折り返しできる。
- Emulator接続を認証永続化の待機より先に行い、復帰時の設定失敗を防いだ。
- Web Locksはブラウザでのみ使用する。Nodeテストではプロセス内キューを使用し、Web Locks非対応の古いブラウザではローカル同期の互換性エラーを表示する。
- ローカル・Pages試験のFirebase環境変数を明示的に空にし、`.env.local`に本番設定があっても本番へ試験データを書き込まない。Firebase試験はdemoプロジェクトのEmulatorへ接続する。
- 公開依頼と空のリポジトリ作成を受けて、実装ブランチをmainへfast-forwardし公開した。既存リモートコミットの上書きは行っていない。
- Firebaseの厳密なワード排他制御は追加しない。ユーザー指定どおり入力の共有、送信時検証、候補確定時の重複除去を使う。
